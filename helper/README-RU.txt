Rust+ Bot — помощник привязки
=============================

ДЛЯ ПОЛЬЗОВАТЕЛЯ
----------------
1. В Telegram-боте активируй подписку: /redeem <ключ>
2. Получи код привязки: /pair  (код действует 10 минут)
3. Запусти rst-pair.exe (двойной клик)
4. Введи код из бота
5. В открывшемся браузере войди в свой Steam-аккаунт (тот, на котором играешь в Rust)
6. Готово — вернись в игру, зайди на сервер, открой меню (Esc) -> Rust+ -> Pair with Server
   Бот сам подхватит привязку и заработает 24/7.

Нужен установленный Google Chrome или Microsoft Edge (для входа в Steam).
Steam-логин происходит на официальном сайте Facepunch — программа НЕ видит твой пароль.


ДЛЯ АДМИНИСТРАТОРА (сборка .exe)
-------------------------------
Требуется Node.js 18+ и публичный HTTPS-адрес ingest-эндпоинта бота
(например, через Cloudflare Tunnel -> http://localhost:8787).

  cd helper
  build.cmd https://ВАШ-ТУННЕЛЬ/pair/ingest

Готовый файл: helper\build\rst-pair.exe — выложи его по адресу HELPER_DOWNLOAD_URL.

Без сборки можно запускать и из исходников:
  cd helper
  npm install
  set RST_INGEST_URL=https://ВАШ-ТУННЕЛЬ/pair/ingest
  npm start
